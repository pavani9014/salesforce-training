# Salesforce Platform Basics

## 1. What is Salesforce Platform?

Salesforce Platform is a cloud-based platform used to build business applications, manage customer relationships, automate workflows, and store data.

It provides:
- Low-code configuration tools
- Apex programming support
- Data management features
- Reporting and dashboards
- Application customization

Salesforce allows users to build applications quickly using both configuration and coding approaches.

---

# 2. Salesforce Concepts

## App
An App in Salesforce is a collection of related tabs, objects, and tools grouped together for a specific business purpose.

Examples:
- Sales App
- Service App
- DreamHouse App

Apps help users access features from one place.

---

## Object
An Object is a database table used to store information in Salesforce.

Examples:
- Account
- Contact
- Opportunity

Objects contain:
- Fields
- Records
- Relationships

Types:
- Standard Objects
- Custom Objects

---

## Tab
A Tab is a user interface component used to access objects, records, reports, and dashboards.

Examples:
- Accounts Tab
- Contacts Tab
- Reports Tab

Tabs improve navigation inside Salesforce applications.

---

# 3. Configuration vs Coding

| Configuration | Coding |
|---|---|
| No programming required | Requires programming |
| Uses clicks and drag-and-drop | Uses Apex code |
| Faster and easier | Used for advanced logic |
| Managed in Setup | Written in Developer Console |
| Example: Validation Rule | Example: Apex Trigger |
| Example: Flow Builder | Example: Apex Class |
